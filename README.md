# Задачи: приложение для iPhone

Сборка идёт в облаке GitHub (нужен только браузер и Windows-компьютер), установка на iPhone через Sideloadly с бесплатным Apple ID.
Приложение работает 7 дней, потом его нужно переустановить (шаг 7).

1. Зарегистрируйтесь на github.com и создайте репозиторий (кнопка New repository, имя любое, например fieldtasks, можно Private).
2. Распакуйте этот архив. В репозитории нажмите Add file → Upload files и перетащите ВСЁ содержимое папки (Sources, Config, .github, project.yml). Нажмите Commit changes.
   Если папка .github не загрузилась: Add file → Create new file, в поле имени введите .github/workflows/build.yml, вставьте содержимое файла build-workflow.yml и сделайте Commit.
3. Откройте вкладку Actions → слева «Build IPA» → Run workflow. Подождите 5–10 минут до зелёной галочки.
   Если появился красный крестик: откройте запуск, скопируйте текст ошибки и пришлите Claude.
4. В завершённом запуске внизу, в разделе Artifacts, скачайте FieldTasks-ipa и распакуйте zip: внутри будет FieldTasks.ipa.
5. На Windows установите iTunes и iCloud с сайта apple.com (не из Microsoft Store), затем Sideloadly (sideloadly.io). Подключите iPhone кабелем и нажмите «Доверять». В Sideloadly введите свой Apple ID, перетащите FieldTasks.ipa и нажмите Start.
6. На iPhone: Настройки → Основные → VPN и управление устройством → доверьтесь своему Apple ID. Если iPhone просит: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить (потребуется перезагрузка).
7. Раз в 7 дней: подключите iPhone и повторите шаг 5 с тем же IPA и тем же Apple ID, поверх установленного приложения. Данные при этом обычно сохраняются. Не удаляйте приложение вручную: вместе с ним удалятся и данные.

Данные хранятся только на этом iPhone. Из веб-версии они не переносятся.
